# 3D Express Studio

استوديو تصميم ثنائي وثلاثي الأبعاد يعمل في المتصفح من ملف HTML واحد، مع خط زمني للحركة.

> برمجة: حسن الفيفي · Hassan Alfaifi — للدعم: aboanas990@yahoo.com

## التشغيل
1. افتح `3d-express-studio5.html` في Chrome أو Edge.
2. يحتاج اتصالًا بالإنترنت عند أول فتح لتحميل المكتبات (Three.js 0.160 و GSAP 3.12.5 وخط IBM Plex Sans Arabic، ومحرك three-gpu-pathtracer 0.0.23 عند أول رندر واقعي).
3. الواجهة بالعربية والإنجليزية (زر «اللغة»).

> `3d-express-studio2.html` نسخة أقدم محفوظة للرجوع إليها. النسخة الحالية هي studio5.

## تخطيط المحرر (جديد في 5.1)
يفتح البرنامج الآن بتخطيط محرر الألعاب المألوف عالمياً، ويمكن الرجوع للتخطيط الكلاسيكي بزر «التخطيط الكلاسيكي» في الشريط العلوي (يُحفظ اختيارك).

- **التسلسل الهرمي** (يسار): كل كائنات المشهد، مع زر «+» لإنشاء مكعب أو كرة أو ضوء أو كاميرا.
- **المشهد / اللعبة** (الوسط): «المشهد» للتحرير بالأدوات، و«اللعبة» يعرض ما تراه **الكاميرا الرئيسية** بلا أدوات، مع نسب عرض (حر، 16:9، 4:3، 9:16، 1:1).
- **المفتّش** (يمين): خصائص الكائن المحدد، وللكاميرا زاوية الرؤية وزر «مطابقة العرض الحالي».
- **اللوحة السفلية**: «المشروع» (المكتبة بمجلداتها)، «وحدة التحكم» (الرسائل والتحذيرات والأخطاء مع الدمج والتصفية)، «الخط الزمني».
- **شريط الأدوات**: تحديد Q، تحريك W، تدوير E، تحجيم R، محاور عالمية/محلية، وفي المنتصف ▶ تشغيل، ⏸ إيقاف مؤقت، ⏭ خطوة إطار.
- **وضع التشغيل**: ▶ يحفظ لقطة من المشهد ويشغّل الحركة من البداية في عرض «اللعبة»، والمحرر يتلوّن ليذكّرك أنك في وضع التشغيل. عند الإيقاف يعود المشهد كما كان تماماً، وأي تعديل أثناء التشغيل يُلغى.
- تبويبات الشريط (الرئيسية، إنشاء…) صارت قوائم: انقر التبويب لتظهر أدواته، وانقره مرة أخرى لإخفائها.
- اللوحات قابلة لتغيير الحجم بالسحب من حوافها، وعلى الجوال تظهر «التسلسل الهرمي» و«المفتّش» كأدراج منزلقة.

## جودة العرض والرندر الواقعي (جديد في 5.1)
- **أربعة مستويات جودة** من شريط «العرض النهائي» أو من المفتّش عند عدم تحديد أي كائن: أساسي، متوازن، عالٍ، سينمائي.
- **المؤثرات** تعمل في نافذة المشهد وعرض اللعبة والفيديو والصورة النهائية: إطباق محيطي (AO) يعطي ظلال التلامس، توهج (Bloom) للمصابيح والنيون، تنعيم حواف، تدرّج ألوان (تعريض، تباين، تشبع، تظليل طرفي)، واختيار تحويل الألوان ACES أو AgX.
- **سماء واقعية**: من «العرض ← الخلفية ← سماء واقعية». الشمس تضيء المشهد وتنعكس على المعادن، ويُحرَّك اتجاهها وارتفاعها من المفتّش.
- **رندر واقعي بتتبّع المسار (Path Tracing)**: في نافذة «الرندر النهائي» اختر المحرك «واقعي»، وحدّد العيّنات (64 إلى 1024) والارتدادات. الزجاج والمعادن والظلال الناعمة والإضاءة غير المباشرة تُحسب كما في الواقع، والصورة تتحسن أمامك ويمكن إيقافها وحفظها في أي لحظة. يُحمَّل المحرك عند أول استخدام فقط (يحتاج الإنترنت أول مرة).
- إذا كان الجهاز ضعيفاً وانخفض العرض تحت 18 إطاراً في الثانية، تنخفض الجودة تلقائياً إلى «متوازن» بلا إطباق محيطي.

## الميزات
- **المشهد:** مشهد جديد، فتح مشروع أو استيراد نموذج، حفظ المشروع، مشهد تجريبي، مكتبة عناصر تُسحب إلى المشهد، ومستكشف المشهد ولوحة الخصائص.
- **العرض:** منظور، أمامي (1)، يمين (3)، علوي (7)، وأوضاع العرض المصمت.
- **الحركة:** خط زمني بمدة قابلة للضبط، تكرار، وتنعيم حركة GSAP، مع مفتاح يدوي (K) ومفتاح تلقائي (N) وحذف المفتاح عند المؤشر.
- **الإخراج:** تصدير بعدة صيغ، وتصيير نهائي (Final Render).

## اختصارات لوحة المفاتيح
| الاختصار | الوظيفة |
|---|---|
| Space | تشغيل / إيقاف |
| Ctrl+P | تشغيل / إيقاف وضع التشغيل |
| Ctrl+Shift+P / Ctrl+Alt+P | إيقاف مؤقت / خطوة إطار |
| Q / W / E / R | تحديد / تحريك / تدوير / تحجيم |
| Ctrl+S | حفظ المشروع |
| Ctrl+Z / Ctrl+Y | تراجع / إعادة |
| K / N | إضافة مفتاح / مفتاح تلقائي |
| 1 / 3 / 7 | عرض أمامي / يمين / علوي |

القائمة الكاملة من زر «اختصارات لوحة المفاتيح» داخل البرنامج.
